## 2024-03-24 - Accessibility: Focus Indicators & Contextual Action Feedback
**Learning:** Native `focus` styles can clash destructively when custom components (like buttons/inputs/custom sliders) define their own active/hover states, making the UI feel inconsistent while causing keyboard-only users to lose track of their position on the page. Meanwhile, icon-only increment/decrement buttons (like on Steppers) completely lack context for screen readers if missing robust aria-labels.
**Action:** Always use the CSS pseudo-class `:focus-visible` globally (with an outline offset to preserve component boundaries) over regular `:focus` to only trigger when navigated by keyboard. Always inject context-aware labels (e.g. `aria-label="Increase {label}"`) into generic action buttons to ensure screen readers explicitly narrate the consequence of the action.
