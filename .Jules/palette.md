## 2026-07-13 - Global focus-visible for custom industrial UIs
**Learning:** Using a global `:focus-visible` with a brand color outline and offset is highly effective in complex industrial React apps (like SiloOS) where custom button states (active/hover) would otherwise clash with standard `:focus` styling during keyboard navigation.
**Action:** Apply this global CSS pattern in similar industrial projects before attempting to style individual component focus states.
