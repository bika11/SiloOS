## 2025-02-16 - Prevent Timing Attacks on Token Validation
**Vulnerability:** A timing attack vulnerability existed in `ble_bridge.py` where the WebSocket authentication token (`client_token`) was compared to the secret (`AUTH_TOKEN`) using a standard string equality check (`client_token != AUTH_TOKEN`). This could allow an attacker to guess the token by measuring the time it takes for the comparison to fail.
**Learning:** Standard string equality checks in Python short-circuit when a mismatch is found, leading to variable execution times based on how many characters match the expected string. This pattern is dangerous for security tokens, passwords, and API keys. Additionally, `client_token` can be `None` if the `auth` query parameter is missing, which could cause a `TypeError` if passed directly to cryptographic functions.
**Prevention:** Always use `secrets.compare_digest(a, b)` for comparing security tokens or sensitive strings. Ensure that potentially missing input (like query parameters) are explicitly checked for `None` before being passed to `secrets.compare_digest` to prevent runtime errors and crashes.
